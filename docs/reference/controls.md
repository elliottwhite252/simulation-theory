# Controls

Simulation Theory uses a keyboard. Controllers and touchscreens aren't supported yet.

## In game

| Action | Keys |
| --- | --- |
| Walk | **W A S D** or the **arrow keys** |
| Shoot | **Z**, **Space**, or **click** |
| Melee | **X** |
| Mute or unmute music | **M** |

You can walk in four directions. Up and down move Iris across the width of the street, not into the air.

## Title screen

| Action | Keys |
| --- | --- |
| Start the game | **Space** or **Enter** |
| Mute or unmute music | **M** |

## Cutscenes

| Action | Keys |
| --- | --- |
| Next panel | **Space** or **Enter** |
| Skip the cutscene | **Esc** |

## After the game

| Screen | To return to the title screen |
| --- | --- |
| Game over (**SIGNAL LOST**) | Press **Z**, **X**, or **Space**, or click |
| Victory | Press any key, or click |

## Timing

| Action | Cooldown |
| --- | --- |
| Shoot | 220 ms between shots |
| Melee | 360 ms between swings |
