# Simulation Theory

Simulation Theory is a single-player, side-scrolling beat-em-up set in a synthwave neon city. You play as Iris, who's taking on OmniCast, the media company that controls almost every screen and speaker in the city. The game runs in the browser and is built with Phaser 3, TypeScript, and Vite.

The game is an early prototype. It has an opening cutscene, two enemy rooms, and a boss fight.

## Who these docs are for

These docs serve two readers:

- **Players** who want to run the game and learn how to play. Start with the Quickstart and Controls pages.
- **Developers** who want to change or extend the game. The how-to guides and reference pages assume you know basic TypeScript and can use a terminal.
